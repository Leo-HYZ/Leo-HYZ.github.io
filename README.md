# Academic Portfolio

Bilingual, responsive academic portfolio for GitHub Pages. Plain HTML, CSS, JS; no build steps or dependencies (except optional Google Fonts).

## Publish to GitHub Pages
1. On GitHub, create a **public** repository named `Leo-HYZ.github.io` under account `Leo-HYZ` (if it does not exist).
2. Upload `index.html`, `style.css`, `script.js`, and the `.github/workflows/pages.yml` file, preserving the paths. GitHub's browser uploader can upload a folder, or use Git to preserve hidden `.github` paths.
3. Open **Settings → Pages → Build and deployment → Source**, choose **GitHub Actions**.
4. On the **Actions** tab, check `Deploy GitHub Pages`; once successful, visit `https://Leo-HYZ.github.io/`.

If using a different repo name, URL becomes `https://Leo-HYZ.github.io/<repo-name>/`.

## Edit
- Open `index.html` to change biography, topics, research output, GitHub URL and text in both `data-en` and `data-zh` attributes.
- Replace research descriptions and example publication rows with *verified* personal content.
- Change styles in `style.css`.
- Switch language or light/dark mode through the header controls.

**Privacy:** No personal email, phone, or unpublished manuscript details were invented. Replace generic text before sharing widely.
